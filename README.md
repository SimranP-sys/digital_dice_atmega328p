# atmega328p_digital_dice
The given Random_num file provides embedded C (bare metal) code for this project. 
The project generates a random number between 0-6 and display it on 7 segment display using atmega328P uC. The project aims to generate random numbers using only stdlib library and counters. 

Components required : 
a 7 segment common anode display
Arduino Uno board
Arduino IDE
buzzer
push button 
and resistors.
